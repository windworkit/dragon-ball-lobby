# Patched Dragon Ball Lobby functions

This folder contains a repaired copy of the original Shenron Valley function.

- `data/dblobby/function/regions/shenron_valley.mcfunction`: original 1.0
  structure with its three oversized terrain fills split into legal sections.

This is **not yet a complete datapack**. It contains only the repaired region
function. To use it, start from the original 1.0 datapack, replace the matching
Shenron Valley function with this file, and keep the rest of the original
functions and metadata. Back up the world first.

The untouched original remains under `versions/original/`.
