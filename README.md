# Dragon Ball Lobby Datapack

A Minecraft Java 1.21.1 datapack for generating a Dragon Ball-inspired lobby.

## Status

Project setup is in progress. The first implementation targets vanilla blocks so it can run while the companion mod is still in development.

## Planned areas

- Central spawn plaza
- Capsule-style futuristic city
- World Martial Arts Tournament grounds
- Kame House island
- Kami's Lookout
- Shenron sanctuary

## Build and installation

The datapack will be packaged with `pack.mcmeta` at the ZIP root. Copy the ZIP into a world's `datapacks` folder, run `/reload`, and use the documented generation function from a safe, open area.

See the datapack folder and build workflow as they are added.
